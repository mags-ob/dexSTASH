# Personal rules (example)

Copy this file to `rules/personal.md` to add your own preferences for the AI assistant you work with. That
file is ignored by git, so it never reaches the repository. Personal rules can add to the
[core](core.md) rules and the project rules in [AGENTS.md](../AGENTS.md) but never loosen them.

Things that belong here:

- Your shell (for example "give PowerShell commands, not bash").
- How you deploy and test on your own server. Keep server names, paths and addresses here, never in the
  repository.
- How much you want the assistant to do before checking with you.
- Limits you're watching, such as your usage plan.
